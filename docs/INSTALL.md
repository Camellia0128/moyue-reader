# 安装、升级与排障

## 安装与升级

1. 准备 Android 8.0+ 平板和基于 Chromium 110+ 的系统 WebView。
2. 从本仓库 Releases 下载 APK，与同页 SHA256 摘要核对。
3. 在文件管理器打开 APK，按系统提示允许该文件来源安装。完成后可关闭该来源安装许可。
4. 更新前在墨阅导出 .moyue 备份，选择应用私有目录之外的位置，再以相同签名的新包覆盖。

包名 cn.moyue.reader。历史文件名墨阅-1.0.0.apk 不代表包内版本；当前正式包为 1.2.0。调试包或其他签名的包无法覆盖正式包，先备份，再决定卸载或修改包名并行安装。

## 数据与空间

导入会复制原文件到应用私有存储，并保存解析正文、封面、进度和笔记。PDF 缓存、正文索引、词典与字体也占空间，因此不是只记录原文件路径；删除下载目录原书不会删除应用内副本。

单本上限 100 MB。完整备份包含原书、进度、书签、笔记、收藏集、生词及阅读偏好，原文件合计最多 1 GB；字体与词典不包含在内，需重新导入。备份文件也占空间，导出前请留足余量。

卸载、清除数据会移除私有书库。系统备份不能替代手动导出。备份到网盘可通过系统文件选择器或网盘 App 手动上传/下载，目前没有百度网盘直连和自动同步。

## 常见问题

**PDF 在其他软件能打开，这里打不开：** 检查文件完整性、加密与容量限制，尝试兼容 PDF 入口。PDF.js 和 Android 引擎覆盖范围不同。重新导入同一原文件可修复应用内副本，保留已有阅读记录；可先返回书库操作其他书，不必清空全部数据。

**扫描 PDF 不能选字或搜索：** 当前没有 OCR，需先添加文字层；原生兼容引擎文字能力也受 Android 版本影响。

**白屏或 WebView 过旧：** 通过设备认可的渠道更新系统 WebView。华为及第三方 Android 兼容环境的 WebView 和文件选择器可能不同，兼容性以实际设备验证为准。

**更新无法安装：** 检查存储空间、Android 版本、包版本号与签名。不要直接清除数据，先备份。

**灰色和全刷与 Kindle 不同：** 灰纸、白场和黑白图层是软件模拟。硬件残影与刷新波形取决于设备，没有厂商适配不能保证真实电子纸全刷。

报告问题请附应用、设备、Android、WebView 版本及重现步骤。请使用原创最小样例，不要公开私人书籍和个人阅读数据。
